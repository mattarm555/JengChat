JENG CHAT CARD ASSETS
=====================

The client loads PNGs from this folder using these exact names:

Spades:   2S.png ... 10S.png, JS.png, QS.png, KS.png, AS.png
Hearts:   2H.png ... 10H.png, JH.png, QH.png, KH.png, AH.png
Diamonds: 2D.png ... 10D.png, JD.png, QD.png, KD.png, AD.png
Clubs:    2C.png ... 10C.png, JC.png, QC.png, KC.png, AC.png
Back:     back.png

A complete starter deck is included. You can replace any of these PNGs later
with your own art without changing the C++ code, as long as the filenames stay the same.

Blackjack and Poker share the same card renderer and this same deck.
